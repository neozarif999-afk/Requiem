# Drop your images here

The portfolio (`portfolio/index.html`) looks for these exact filenames in this folder.
Add a file with the matching name and it replaces the placeholder automatically — no code changes needed.

| Artwork                                   | Filename                              |
|--------------------------------------------|----------------------------------------|
| Batman ink portrait                         | `batman.jpg`                          |
| Wolverine                                   | `wolverine.jpg`                       |
| Doctor Strange                              | `doctor-strange.jpg`                  |
| Inter University Music Fest 2026 poster     | `inter-university-music-fest.jpg`     |
| Intra University Musical Workshop 6 poster  | `intra-university-workshop.jpg`       |
| Your headshot/portrait (for the About section) | `profile.jpg`                      |

Any common image format works if you rename it to match exactly (`.jpg`, `.jpeg`, `.png`, `.webp` — just update the extension in the `file:` field for that project inside the `projects` array near the top of the `<script>` tag in `index.html` if you don't use `.jpg`).
